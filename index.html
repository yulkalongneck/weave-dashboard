Impact model

This dashboard scores merged PRs from public GitHub metadata. It favors PRs with clear problem and change descriptions, focused maintainability work, modularity signals, and concrete testing evidence. Commit counts and lines changed are deliberately excluded from the score. With a valid token, PR metadata is fetched through GitHub GraphQL, and commit-heavy forks use parallel REST pagination after discovering the last page. Without a token, the app falls back to slower REST-only fetching.
